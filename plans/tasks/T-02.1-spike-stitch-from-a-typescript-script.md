## Proof

_Commands run, outputs, scores, file paths. The auditor checks this section._

Full result: `docs/spikes/T-02.1-stitch.md` (answers table, commands, numbers, findings, ADR notes).
Scripts ran in a throwaway scratchpad folder outside the repo; the project lead ran them in their own terminal
(keychain access from the chat was blocked, which keeps the key out of the chat).

- **Install:** `npm i @google/stitch-sdk` → v0.3.5 in 19 s, 0 vulnerabilities; `node spike.ts` runs on Node 24 with
  `"type": "module"`, no build step.
- **Key from keychain:** Windows generic credential `ai-sdlc/stitch` read by `CredRead` → `found: true`, 1179 ms;
  key scrubbed from every output (`[KEY]`), never printed, never in a file.
- **3 screens:** sign-in 64.0 s, list 55.2 s, form 51.7 s; each with HTML (16.7–34.8 kB) and PNG (24.7–73.5 kB),
  HTTP 200, plus 14 data fields per screen.
- **Edit + HTML and image:** form edit 28.2 s → new screen ID, HTML 28.9 kB, PNG 70.0 kB; Category dropdown added
  (selects 1 → 2, labels 6 → 7; checked on the PNG).
- **Time and quota; account type:** times above; no quota API in the SDK or its 15 MCP tools; Stitch shows 400 left
  after the run (before not noted); company Google Workspace account.
- **Plugin secrets not in Bash:** Claude Code manifest reference, "Where each variable resolves": plugin variables
  "aren't present in the environment of commands Claude runs through the Bash tool" → the script reads the
  keychain itself (as ADR-11 says).
- **Stitch MCP compared:** not connected in Claude Code (`claude mcp list`); the SDK is an MCP client of the same
  endpoint `https://stitch.googleapis.com/mcp` (header `X-Goog-Api-Key`), so same tools and limits. Not added with
  `claude mcp add` (would store the key in a plain file, R9); project `.mcp.json` (commit ce91dd7) uses
  `${STITCH_API_KEY}` from the environment, no key in any file; live test is an inbox item for T-02.8.
- **Extra finding:** `list_screens` = 0 and `get_screen` fails ("invalid argument") for all 4 screens, also after
  21 min (`resume.ts`) → no read-back, no job ID; "resumable" in ADR-11 and ADR-25 not proven.
- **ADR-11:** confirmed with notes (`docs/adr/ADR-11-*.md` Notes, 2026-10-03); affected for T-02.8: ADR-11 wording,
  ADR-25, 3.6 design adapter `resume`, 3.7 keychain reader on macOS/Linux, ADR-09/ADR-13 (field names drift).
- **Checks:** `python tools/check_generality.py` → `ok (0 files, 356 terms)`, exit 0;
  `python -m unittest discover -s tools/tests` → `Ran 11 tests … OK`.
