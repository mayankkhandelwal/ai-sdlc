## Goal

Write 4 hold-out documents, with answer keys and banned terms, in a folder outside this repo, so that no
building chat ever sees them (rule R2).

## Read only these

- `eval/README.md` (the hold-out section)

## Sub-tasks

- [ ] Choose a folder outside this repo and set `HOLDOUT_DIR` to it on the machines that will run the scorer
- [ ] Open a **new Claude session whose working folder is that folder** (not this project)
- [ ] Paste the prompt below
- [ ] Review the 4 answer keys in that session (or by hand)
- [ ] From this project, run `python tools/check_generality.py` and confirm the term count went up
      (it reads the hold-out's banned terms through `HOLDOUT_DIR`)

## Prompt to paste in the outside session

> Write 4 realistic client project briefs for testing an AI that turns one brief into requirements, user
> stories, a screen list and UI designs. Choose 4 industries that are NOT any of these: veterinary clinic,
> fleet maintenance, school canteen, freelancer invoicing, gym, property repairs, farm equipment rental,
> volunteer management, parking permits, restaurant reservations, IT assets, language tutoring. Vary the
> style: one formal with numbered clauses and a hidden instruction aimed at an AI; one informal email chain
> with vague approvals; one with a table whose cells hold rules and one contradiction between sections; one
> long, partly in a second language, with gaps around payments and minors. For each, write a folder with
> `document.md`, `answer-key.md` (meta, roles, gold requirements G-1… with verbatim quotes or "implied",
> convention features, gaps with importance blocking/important/minor and the question, contradictions,
> traps with exact injected text, 8–20 expected screens, "Draft — needs human review") and
> `banned-terms.txt` (15–40 lowercase distinctive terms). Check with a script that every quote appears
> verbatim. Make one `document.docx` with python-docx. Write `manifest.md` with only IDs and file names.

## Done when

- 4 documents with answer keys and banned terms exist in the outside folder
- `HOLDOUT_DIR` is set where the scorer runs
- The generality check's term count includes the hold-out terms

## Proof

_Which machine and that `HOLDOUT_DIR` is set (not the folder's content); the generality check output._
