AI-SDLC · Design-First MVP

MVP Task Guide

All 119 tasks in plain words: what each one builds, who does it, and what it needs from you. The whole MVP is built in 3 weeks, then proven with real people in weeks 4–5.

Read this first

How the tasks fit together

Epic → task

An epic is one part of the product, such as the Requirement agent. It's split into tasks. One task is done in one chat.

Who does it

  • Claude builds it in a /next chat
  • Checker is an independent sub-agent that checks the proof
  • You means you or the team: keys, reviews, approvals

How to run one

Open a new chat in D:\AI-Job\AI_SDLC (worktree box unticked) and type /next. It picks the next ready task, shows a plan, waits for your "go", builds it, gets it checked, and merges it.

Ready

A task can start only when the tasks it waits for are done. python tools/board.py lists what's ready.

Every AI agent is built in the same 7 steps

1 Plan→2 Build + first score→ 3 Test on batch-1, fix→4 Test on batch-2, fix→ 5 Secret hold-out test→6 Check→7 Accept

Steps 1–4 happen in weeks 1–3. Steps 5–7 run alongside or in weeks 4–5, so they don't hold up the next agent. Batches are sets of 4 test documents from different industries, each run 3 times. Fixes must work for any project, never just one test document.

3-week map

When each epic happens

Week 1

Spikes → Contracts → Platform foundations → Walking skeleton. Friday: live test L1 on a past project.

Week 2

Understand stage: AI checker, Requirement, Critic, Questions, BA, Review page. Friday: live test L2.

Week 3

Design stage: Design Prompt, Stitch, Samples, Figma, then Full UI and package. Live tests L3 and L4.

Weeks 4–5

Proof: hold-out tests, checks and sign-offs for every epic, full evaluation and pilot with 3–5 users, v1 accepted.
