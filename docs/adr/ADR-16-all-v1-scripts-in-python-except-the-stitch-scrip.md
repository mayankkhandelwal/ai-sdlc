# ADR-16 · All v1 scripts in Python except the Stitch script (TypeScript)

- **Status:** Accepted
- **Source:** `docs/architecture/06-decisions-and-risks.md` (6.1); audits in `docs/audits/`

## Decision

All v1 scripts in Python except the Stitch script (TypeScript)

## Rejected options

All Python (no official Stitch SDK); all TypeScript

## Consequences

Two runtimes; each script uses the best-supported library
