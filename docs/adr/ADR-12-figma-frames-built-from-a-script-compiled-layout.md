# ADR-12 · Figma frames built from a script-compiled layout file, carried by an agent limited to Figma's write tool and one file; gated by a test (ADR-23)

- **Status:** Accepted
- **Source:** `docs/architecture/06-decisions-and-risks.md` (6.1); audits in `docs/audits/`

## Decision

Figma frames built from a script-compiled layout file, carried by an agent limited to Figma's write tool and one file; gated by a test (ADR-23)

## Rejected options

Skip Figma; agent draws frames freely

## Consequences

Still high Claude usage per screen; consistent, editable frames with components
