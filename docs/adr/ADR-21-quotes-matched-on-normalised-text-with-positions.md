# ADR-21 · Quotes matched on normalised text, with positions; tables cited by cell; IDs stable across versions; "convention" items

- **Status:** Accepted
- **Source:** `docs/architecture/06-decisions-and-risks.md` (6.1); audits in `docs/audits/`

## Decision

Quotes matched on normalised text, with positions; tables cited by cell; IDs stable across versions; "convention" items

## Rejected options

Exact text match only; new IDs per version

## Consequences

Fewer false failures; links never break
