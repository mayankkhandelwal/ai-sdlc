# ADR-17 · New apps only in v1; existing apps in v1.1 without building them

- **Status:** Accepted
- **Source:** `docs/architecture/06-decisions-and-risks.md` (6.1); audits in `docs/audits/`

## Decision

New apps only in v1; existing apps in v1.1 without building them

## Rejected options

Existing apps now; building unknown repos

## Consequences

Smaller v1; safer
