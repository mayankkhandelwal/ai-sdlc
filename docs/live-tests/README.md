# Live project tests

Reports from testing the system on real project briefs (epic E-18; plan in `docs/plan.md`).

| Report | Test | Mode |
|---|---|---|
| `L1.md` | Skeleton on 1–2 past projects | Shadow |
| `L2.md` | Understand stage on a current project | Shadow, then assisted |
| `L3.md` | Design on a current project | Assisted |
| `L4.md` | One project end to end | Assisted |

**Rules for every report:** no client names, product names or confidential content; describe failures
in general words (rule R1); list measurements (time, misses, inventions, edits, ratings) and the
changes proposed (also added to `plans/inbox.md`).
